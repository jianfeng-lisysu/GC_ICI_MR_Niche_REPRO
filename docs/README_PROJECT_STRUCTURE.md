# GC_ICI_MR_Niche Reproducibility Package

This folder contains files required to reproduce the gastric cancer ICI/MR immune-niche project.

Main analysis:
- FinnGen R13 gastric cancer outcomes
- OpenGWAS protein QTL instruments
- GSE167297 single-cell RNA-seq expression validation

Current prioritized axis:
- FCN1-TNFSF12 myeloid-stromal immune-excluded niche

Key cis-only replicated candidates:
- FCN1
- SCARF2
- TNFSF12
- CD1D
- DLL1

Secondary candidates:
- CD274/PD-L1
- SIGLEC7
