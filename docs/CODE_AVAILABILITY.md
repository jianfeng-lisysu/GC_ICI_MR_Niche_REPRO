# Code availability

Repository:
https://github.com/jianfeng-lisysu/GC_ICI_MR_Niche_REPRO

The repository contains reproducible analysis scripts for the proteome-wide MR,
candidate cis-pQTL MR, single-cell localization, and spatial transcriptomic analyses.

Raw and individual-level data are not distributed in this repository.
Public datasets should be obtained from their original data repositories.

OpenGWAS authentication is provided through the user-level `OPENGWAS_JWT`
environment variable and is not stored in the code.

Random seeds and deterministic-analysis declarations will be documented
for each analysis script before public release.
